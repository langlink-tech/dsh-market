# LangLink dsh plugin market

Public plugin market index for LangLink DeepSeek Harness (dsh) plugins.

## Add the market

In dsh, open **Plugins → Discover**, add this index URL:

```text
https://langlink-tech.github.io/dsh-market/index.json
```

## Available plugins

- `@langlink/dsh-l10n` — LangLink localization tools: XLIFF/SDLXLIFF, TM/term matching, deterministic QA, translate/polish, DOCX/XLSX/PPTX extraction/backfill.
  - npm: https://www.npmjs.com/package/@langlink/dsh-l10n
  - source: https://github.com/langlink-tech/langlink-harness-toolsets

## Format

The index follows the official dsh plugin market index format 1:

- [plugin-market-index](https://www.npmjs.com/package/@deepseek-ai/dsh-plugin-market-index)
- [plugin-market](https://www.npmjs.com/package/@deepseek-ai/dsh-plugin-market)
